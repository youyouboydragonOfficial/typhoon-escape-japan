# Typhoon Escape // 日本列島防衛線

Windows向けのオリジナル・プロシージャル描画ゲームです。日本列島を操作し、接近する台風の中心と渦を避けながら防衛スコアを伸ばします。

## 遊び方

- 矢印キー または WASD: 移動
- P: 一時停止
- ESC: メニューへ戻る / 終了
- 台風に触れると安全度が下がります

## 著作権について

ゲーム内の地形、台風、UI、アニメーションはすべてこのリポジトリ内のコードから生成されます。第三者のゲーム画像、ロゴ、音源、フォント素材は同梱していません。動画はゲーム性・テンポの参考としてのみ扱い、映像・素材・画面構成の直接コピーはしていません。

## ゲームモード

- **STANDARD / 観測型**: 段階的に激しくなる基本モード
- **CHAOS FORECAST / 予測不能**: 予測線が外れる急旋回と急発達
- **LANDFALL RUSH / 連続襲来**: 複数台風が一気に押し寄せる
- **SEASON SCENARIO / 季節変動**: 前線と熱帯低気圧を含む波状攻撃

メニューで左右キー（または A / D）を押すとモードを選べます。台風には予測線を表示しますが、「CHAOS FORECAST」では急旋回・急発達により予測が外れます。

## ビルド

```powershell
dotnet run
./build-release.ps1
```

`TyphoonEscapeJapan-Setup-win-x64.exe` は .NET 10 Desktop Runtime を同梱したユーザー単位インストーラーです。管理者権限なしでインストールし、デスクトップとスタートメニューにショートカットを作ります。「アプリと機能」からアンインストールできます。開発環境では `dotnet run` が利用できます。
